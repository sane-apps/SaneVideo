# Privacy Policy - SaneVideo

**Last Updated: December 2025**

## Our Commitment to Privacy

SaneVideo is built with privacy as a core principle. We believe your video content is personal and should stay on your device.

## Data Processing

### 100% On-Device Processing (Default)

By default, **all AI processing happens entirely on your Mac**. This includes:

- **Magic Fix features**: Silence removal, filler word detection, auto-enhancement
- **Video analysis**: Face detection, text recognition, saliency detection
- **Audio processing**: Voice isolation, enhancement, transcription
- **Caption generation**: Speech-to-text using Apple's on-device Speech framework

**Your videos never leave your Mac** when using on-device features.

### Optional Cloud AI Services

SaneVideo supports optional cloud AI services for enhanced features:

- **OpenAI API**: For advanced semantic analysis and content generation
- **Google Gemini API**: Alternative cloud AI provider

**Important**: Cloud AI services are **completely optional** and only used if you explicitly configure API keys in Settings. When enabled:

- Only transcript text (not video) is sent to the cloud service
- API keys are stored securely in macOS Keychain
- You can disable cloud AI at any time
- On-device processing remains available as a fallback

## Data Collection

SaneVideo does **not** collect, transmit, or store:

- Your video files
- Your audio recordings
- Your project data
- Usage analytics
- Personal information

## Local Storage

All project files, recordings, and exports are stored **locally on your Mac**:

- Projects: `~/Library/Application Support/SaneVideo/Projects/`
- Recordings: `~/Movies/SaneVideo/`
- Temporary files: System temporary directory (automatically cleaned)

## Permissions

SaneVideo requests the following macOS permissions:

- **Camera**: For recording video (only when you start recording)
- **Microphone**: For recording audio (only when you start recording)
- **Screen Recording**: For screen capture functionality

These permissions are **only used when you actively record**. We do not access your camera or microphone in the background.

## Third-Party Services

When using optional cloud AI services:

- **OpenAI**: See [OpenAI Privacy Policy](https://openai.com/privacy)
- **Google Gemini**: See [Google Privacy Policy](https://policies.google.com/privacy)

We recommend reviewing these policies before enabling cloud AI features.

## Your Rights

You have complete control over your data:

- **Delete projects**: Remove projects from the app (files deleted from disk)
- **Disable cloud AI**: Turn off cloud AI services in Settings
- **Export and delete**: Export your videos and delete all local data
