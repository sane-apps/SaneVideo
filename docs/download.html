Download SaneVideo

Free, with every feature. For Macs with Apple silicon running macOS 26 or later.

Download for Mac Mac App Store

Both are the same app. The download here updates itself; the Mac App Store version updates through the App Store.

Install

  1. Open the downloaded ZIP file.
  2. Move SaneVideo to your Applications folder.
  3. Open SaneVideo. Allow camera, microphone and screen recording when macOS asks.

Try it in a minute

Make a short recording, or drag a video into the window. Press Clean Up to cut the silences and filler words, then press Export.

The first Clean Up downloads a speech model once, so stay online for that.
