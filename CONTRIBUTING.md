# Contributing to SaneVideo

Thanks for helping. SaneVideo is free MIT software.

## Quick start

```bash
git clone https://github.com/sane-apps/SaneVideo.git
cd SaneVideo
xcodegen generate
./scripts/SaneMaster.rb verify
```

## Good first work

- Fix a labeled `help wanted` issue
- Improve first-run recording permission copy
- Add a test for a trim, export, or close-window bug you can reproduce

Do not add a paywall. Donate stays optional.

## Requirements

- Xcode 16+
- macOS 15 to build
- [XcodeGen](https://github.com/yonaskolb/XcodeGen)
