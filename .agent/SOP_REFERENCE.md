## What's in the SOP?

The SOP (DEVELOPMENT.md) contains:

1. **Golden Rules** - Critical rules (SaneMaster.rb, xcodegen, 500-line limit, etc.)
2. **Architecture** - System layers, directory structure, concurrency model
3. **Style Guide** - Formatting, SwiftUI patterns, naming conventions
4. **Workflows** - Build, test, verification processes
5. **Troubleshooting** - Common issues and solutions
6. **Testing Strategy** - Unit tests, UI tests, performance tests
7. **Documentation Structure** - How to organize docs

## When to Use the SOP

**Always**:
- Before making any code changes
- When unsure about a workflow
- When encountering build/test issues
- When adding new features
- When creating new files

**The SOP is the single source of truth. Everything else is reference or historical.**
