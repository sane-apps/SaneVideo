Install

  1. Open the downloaded ZIP.
  2. Move SaneVideo to Applications.
  3. Grant camera, microphone, and screen recording permissions when macOS asks.

Good first test

Open SaneVideo, add a local clip or make a short recording, review it in the timeline, try Magic Fix on the selected clip, then use the post-recording save, edit, or share actions.
