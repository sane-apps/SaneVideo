### FAQ Section

**Q: Does SaneVideo work offline?**  
A: Yes! All core features work 100% offline. Cloud AI is optional and only used if you add your own API keys.

**Q: What about updates?**  
A: Lifetime updates are included with your one-time purchase.

**Q: Can I use cloud AI if I want?**  
A: Yes! You can optionally add OpenAI or Gemini API keys in Settings for enhanced features. But it's not required—everything works on-device.

**Q: Why Apple Silicon only?**  
A: We optimize exclusively for M1+ Macs to deliver maximum performance. Intel Macs can't run macOS 26.2+ anyway.

**Q: How does this compare to Final Cut Pro?**  
A: SaneVideo is 83% cheaper, includes screen recording, and focuses on privacy-first AI. Final Cut is better for Hollywood-grade color grading, but SaneVideo is perfect for content creators.

**Q: What's the refund policy?**  
A: We offer a 30-day money-back guarantee. If you're not satisfied, contact us for a full refund.
